Disaster Recovery & Target Machine Migration Guide

Method A: Restore on Windows (XAMPP / WAMP)

  1. Download the backup .sql.gz or .zip.
  2. Run the included restore_moodle_machine.bat script.
  3. Or import manually in CMD: 
    mysql -u root -p -e "CREATE DATABASE moodle DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p moodle < moodle_database.sql
  4. Place moodledata at C:\xampp\moodledata and update config.php.
  5. Run URL replacement CLI to update the host domain: 
    php C:\xampp\htdocs\moodle\admin\cli\replace.php --search=https://service.sjctni.edu/jostel/moodle --replace=http://localhost/moodle

Method B: Restore on Linux (Ubuntu / Debian / Docker)

  1. Transfer the backup archive to your Linux server.
  2. Run the included restore_moodle_machine.sh script.
  3. Or import directly from gzip: 
    zcat moodle_db_dump.sql.gz | mysql -u root -p moodle
  4. Set file ownership: 
    sudo chown -R www-data:www-data /var/moodledata
sudo chmod -R 777 /var/moodledata
  5. Run URL replacement CLI: 
    sudo -u www-data php /var/www/html/moodle/admin/cli/replace.php --search=https://service.sjctni.edu/jostel/moodle --replace=http://your-server-ip/moodle
Command-Line Alternative: You can also run the automated Python backup downloader directly from any terminal:
python trigger_server_backup.py --db
